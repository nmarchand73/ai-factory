# Record architecture decisions

- Status: Accepted
- Date: 2026-01-01
- Job: baseline

## Context
Decisions that shape the structure of the library need to be findable later.

## Decision
We will record each architecturally significant decision as a numbered file in `docs/adr/`.

## Consequences
New contributors can read why the library is shaped as it is. Each decision costs a short file.

## Alternatives considered
- Wiki pages: they drift away from the code and are not reviewed with it.
