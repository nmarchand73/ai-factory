# Code of conduct

We want this project to be a welcoming place to ask questions, report problems and contribute. It follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), summarised here.

**Be respectful.** Give and accept feedback graciously, focus on what is best for the project, and show empathy to
others. Harassment, discrimination, personal attacks, trolling and publishing other people's private information are
not acceptable.

**Scope.** This applies to every project space (issues, pull requests, discussions) and to anyone representing the
project in public.

**Enforcement.** Maintainers may edit or remove comments, issues and contributions that break this code, and may ban
a contributor who does so repeatedly. To report a problem, use GitHub's private
[report content](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam) tool or
contact a maintainer through their GitHub profile. Reports are handled privately and in good faith.

The full text of the Contributor Covenant is available at the link above; it is licensed under CC BY 4.0.
